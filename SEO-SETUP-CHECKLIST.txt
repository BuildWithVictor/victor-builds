VICTOR BUILDS — GOOGLE SETUP AFTER PUBLISHING

The website code already includes page descriptions, headings, image descriptions,
structured business data, robots.txt, sitemap.xml and useful search-targeted guides.

Complete these account-based steps after the final domain is connected:

1. If the final domain is not victorbuilds.com.ng, replace that address in index.html,
   robots.txt and sitemap.xml.
2. Add the website to Google Search Console.
3. Verify domain ownership using the code or DNS record supplied by Google.
4. Submit: https://victorbuilds.com.ng/sitemap.xml
5. Create a Google Analytics property and add its Measurement ID to the website.
6. Create or claim a Google Business Profile for Victor Builds.
7. Use the same business name, phone numbers and website address everywhere.
8. Add genuine links from business and social profiles.
9. Keep publishing helpful, original articles for Nigerian business owners.

Important: good setup helps Google understand the website, but no developer can
honestly guarantee immediate first-page placement. Rankings depend on competition,
website quality, reputation, useful content and time.
