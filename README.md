# Victor Jehu-David Portfolio V2

Static project-led portfolio built with HTML, CSS and vanilla JavaScript.

## Deploy

Upload the contents of this folder to the existing GitHub Pages repository root. Keep the folder structure intact. No build step or database is required.

## Pages

- `index.html` — project-led home page
- `deckler.html`, `anime-social.html`, `era-snacks.html` — case studies
- `404.html` — custom missing-page state

The project uses Google Fonts with robust system fallbacks. All project imagery is stored locally.
