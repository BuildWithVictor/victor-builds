UPLOAD TO CPANEL
1. Open File Manager.
2. Open public_html.
3. Upload the ZIP file.
4. Extract it inside public_html.
5. Make sure index.html is directly inside public_html.

EDITING
- Page content: open the matching .html file.
- Colours/layout: style.css.
- Menu, animations and quote form: script.js.
- Logo/favicon: images folder.
